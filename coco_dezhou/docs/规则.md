# 规则与状态机

本项目实现的是**无限注德州扑克（No-Limit Texas Hold'em）**，采用常见线上玩法：没有前注（ante）、没有 straddle、不支持 straddle/蘑菇，盲注固定（不随时间上涨）。

---

## 1. 座位与盲注

- 座位数 2–8，创建房间时确定。
- 每人起始筹码相同。
- **庄家按钮（D）** 每手顺时针移到下一个参与本手的玩家。
- 2 人单挑时：庄家同时是**小盲**，翻前庄家先行动，翻后大盲先行动。
- 3 人及以上：庄家下家是小盲，再下家是大盲；翻前从**大盲下家（枪口位）**开始行动，翻后从**庄家下家**开始。
- 盲注不足时，玩家投入全部筹码并**全下**。

---

## 2. 一手牌的流程

```
等待开局
  └─ 发牌：每人 2 张底牌（牌堆用 crypto 随机洗牌，只存在服务端）
      └─ 翻前下注  → 翻牌 3 张 → 翻牌圈下注
                     → 转牌 1 张 → 转牌圈下注
                     → 河牌 1 张 → 河牌圈下注
                        └─ 摊牌结算（或提前所有人弃牌）
                           └─ 展示结果 → 下一手
```

每轮下注结束的条件：所有**未弃牌且未全下**的玩家都行动过，并且下注额都追平了当前最高注。

只剩一位玩家没有弃牌时立刻结束，他赢得底池。

---

## 3. 行动与下注

| 行动 | 说明 |
| --- | --- |
| 弃牌 Fold | 放弃本手，已投入的筹码留在底池 |
| 过牌 Check | 只有在无人下注时可用 |
| 跟注 Call | 补齐到当前最高注；筹码不够时自动全下 |
| 加注 Raise | 指定"加注到多少"（本街的总额） |
| 全下 All-in | 推入全部筹码，可不足最小加注 |

规则细节：

- **最小加注额** = 上一次完整加注的幅度（翻前初始等于大盲）。例如大盲 20，有人加注到 60（幅度 40），下一次加注至少要到 100。
- **短码全下**：全下金额不足最小加注时，视为"非完整加注"，后续玩家只能跟注或弃牌，**不会重新打开加注**。
- 已经行动过的玩家，在本轮没有遇到新的完整加注之前，只能跟注或弃牌。
- 大盲在翻前有"最后说话权"：即使所有人都只是跟注，大盲仍可以选择过牌或加注。

---

## 4. 摊牌与边池

1. 每位未弃牌玩家的 7 张牌（2 张底牌 + 5 张公共牌）中取最好的 5 张，比较牌型与踢脚。
2. 按每人本手**总投入**分层计算底池：
   - 第 1 层到最低投入额 → 主池，所有投入 ≥ 该层的未弃牌玩家参与分配；
   - 第 2 层、第 3 层…… → 边池，只有投入 ≥ 该层的玩家参与；
   - 只有一个人投入到的最高层，等于把多出的筹码退还给本人。
3. 平分时余数（奇数筹码）按**庄家左手第一个赢家**的顺序依次多分 1 个。
4. 所有人弃牌只剩一人时，不需要亮牌。

牌型从大到小：同花顺 > 四条 > 葫芦 > 同花 > 顺子 > 三条 > 两对 > 一对 > 高牌；A2345 是最小的顺子。

---

## 5. 时间与掉线

- 每次行动有 `actionSeconds` 秒（10–120，默认 25），界面顶部进度条与座位上的倒计时同步。
- 超时自动行动：**无需跟注时自动过牌，需要跟注时自动弃牌**。
- 掉线：座位保留，轮到他时会因超时自动过牌/弃牌；长时间掉线（2 分钟）自动释放座位。
- 重新打开页面会自动用 token 回到原座位，筹码与底牌都还在。

---

## 6. 房间与局间

- 房主可以「开始牌局」；开启「自动开始下一手」时，摊牌 7 秒后自动发下一手。
- 筹码输光的玩家自动旁观，可在局间「补码」（默认加一个起始筹码，也可在创建房间时开启"输光自动补码"）。
- 本手进行中加入的玩家会等到下一手才发牌。
- 中途离桌视为弃牌，已投入的筹码留在底池。
- 房主离开后自动移交给下一位在线玩家；房间无人 30 分钟后回收。

---

## 7. 状态机

```
waiting ──(房主开始 / 自动开局)──> betting
betting ──(只剩一人未弃牌)──────> showdown（无人摊牌，直接派彩）
betting ──(四条街结束)──────────> showdown（摊牌、边池派彩）
showdown ──(房主开始 / 自动开始)──> betting
```

`betting` 内部的街：`street = 0 翻前 → 1 翻牌 → 2 转牌 → 3 河牌`，每街结束时把桌面注额并入底池并发出下一街公共牌。
