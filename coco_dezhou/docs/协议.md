# 通信协议

两种接入方式共用同一套牌桌逻辑：

- **WebSocket** `/ws`：本项目手机端在用，实时推送。
- **REST** `/api/*`：给 CoCo 作品「HTTP客户端」积木或第三方脚本用，长轮询取状态。

---

## 1. WebSocket

连接：`ws://<host>/ws`（https 页面自动用 `wss://`）。

### 1.1 客户端 → 服务端

| `t` | 其它字段 | 说明 |
| --- | --- | --- |
| `create` | `nickname` `name` `settings{seats,startChips,sb,bb,actionSeconds,autoStart,autoRebuy,timeoutFold}` | 创建房间并成为房主 |
| `join` | `code` `nickname` `token?` | 用房号加入；带 token 表示重连回原座位 |
| `resume` | 同 `join` | 语义同 join（保留兼容） |
| `list` | — | 取房间列表 |
| `action` | `action{type,to?}` `type` = `fold`/`check`/`call`/`raise`/`allin`；`raise` 时 `to` 是"加注到"的本街总额 | 行动 |
| `start` | — | 房主：开始下一手 |
| `rebuy` | — | 补码（局间可用） |
| `sitout` | `value:boolean` | 旁观 / 回座（本手进行中不能旁观） |
| `kick` | `playerId` | 房主：移出玩家 |
| `chat` | `text`（≤60 字） | 发一条房间消息 |
| `chatHistory` | — | 拉取聊天记录（含进出房系统消息，最多 200 条） |
| `history` | — | 拉取对局记录（手牌流水 + 玩家账本） |
| `leave` | — | 退出房间 |
| `ping` | — | 心跳，服务端回 `pong` |

### 1.2 服务端 → 客户端

| `t` | 说明 |
| --- | --- |
| `hello` | 连接建立：`{version, serverTime}` |
| `room` | 进入成功：`{code, playerId, token}`（token 请保存在本地，用于重连） |
| `state` | **核心消息**，每次状态变化都会推送一份完整快照（见 1.3） |
| `rooms` | 房间列表 `{rooms:[...]}` |
| `history` | 对局记录（见 1.4） |
| `chat` | 聊天记录全量 `{list:[...]}`（进房时下发一次，或用 `chatHistory` 主动拉） |
| `chatMsg` | 一条新消息 `{message:{t:'chat',name,pid,text,at}}` |
| `error` | `{message, requestId?}` |
| `left` | 已退出房间 |
| `closed` | 房间被关闭 `{reason}` |
| `pong` | 心跳应答 |

### 1.3 `state` 快照结构

```jsonc
{
  "t": "state",
  "seq": 42,                       // 快照序号，用于长轮询的 since
  "serverTime": 1730000000000,     // 用于校正客户端倒计时
  "room": {
    "code": "522605",
    "name": "周末局",
    "settings": { "seats": 4, "startChips": 1000, "sb": 10, "bb": 20,
                  "actionSeconds": 15, "autoStart": false, "autoRebuy": false, "timeoutFold": true },
    "hostId": "p1_abc",
    "hostName": "阿宝",
    "createdAt": 1730000000000,
    "members": [ { "id": "p1_abc", "name": "阿宝", "seat": 0, "online": true, "isHost": true } ]
  },
  "you": {                          // 我的成员信息（注意：底牌在 table.you 里）
    "id": "p2_xyz", "name": "我", "token": "…", "seat": 3, "isHost": false
  },
  "table": {
    "phase": "betting",             // waiting | betting | showdown
    "handNo": 3,
    "street": 1,                    // 0 翻前 1 翻牌 2 转牌 3 河牌
    "streetName": "翻牌",
    "board": ["2h", "7d", "Qs"],
    "pot": 320,                     // 含本街已下注
    "currentBet": 60,               // 本街最高注
    "minRaise": 40,
    "dealerSeat": 0, "sbSeat": 1, "bbSeat": 2,
    "actorSeat": 3,                 // -1 表示当前没人需要行动
    "deadline": 1730000000000,      // 行动截止时间
    "now": 1729999990000,
    "settings": { … },
    "seats": [                      // 长度 = settings.seats，空位为 null
      { "seat": 0, "pid": "p1_abc", "name": "阿宝", "chips": 1000, "bet": 0,
        "folded": false, "allIn": false, "inHand": true, "sitOut": false,
        "connected": true, "lastAction": "", "lastWin": 0, "isDealer": true,
        "cards": null,              // 别人的底牌永远是 null（摊牌时才公开）
        "cardCount": 2 }
    ],
    "you": {
      "seat": 3, "chips": 940, "bet": 60,
      "cards": ["As", "Kh"],        // 只有自己能看到
      "folded": false, "allIn": false, "inHand": true, "sitOut": false,
      "isTurn": true, "isHost": false,
      "toCall": 40,
      "legal": {                    // 只有轮到自己时才非 null
        "fold": true, "check": false, "call": 40,
        "raise": true, "minTo": 100, "maxTo": 940, "allin": true
      }
    },
    "results": {                    // 摊牌后才有
      "showdown": true,
      "board": ["2h","7d","Qs","Js","2c"],
      "reveals": [ { "seat": 2, "name": "老王", "cards": ["2s","2d"], "handName": "三条 2" } ],
      "awards":  [ { "seat": 2, "name": "老王", "amount": 320, "handName": "三条 2" } ]
    },
    "log": [ { "i": 41, "t": "action", "seat": 3, "name": "我", "label": "加注", "amount": 60 } ]
  }
}
```

> 聊天不放在 `state` 里（每条状态都带会浪费带宽）：进房时单独下发一次 `chat`，之后每条新消息走 `chatMsg`，需要历史时发 `chatHistory`。

客户端只要"整屏重绘"即可，不需要增量合并。

`log.t` 取值：`join` `leave` `hand` `blinds` `post` `street` `action` `timeout` `autositout` `win` `bust` `rebuy` `pot`。

> `timeout` 条目带 `auto`（`fold` / `check`）与 `streak`（连续超时次数）；`autositout` 表示连续 3 次超时已自动旁观。

### 1.4 `history` 快照（对局记录）

请求 `{"t":"history"}`，服务端只回给请求者一条（不会广播）：

```jsonc
{
  "t": "history",
  "code": "921281",
  "totalHands": 3,        // 已完成手数
  "currentHandNo": 4,     // 正在进行的编号
  "inPlay": true,         // 是否有牌局进行中
  "players": [            // 玩家账本
    { "seat": 0, "name": "阿宝", "buyIn": 2000, "chips": 1180, "inPlay": 60, "delta": -820, "sitOut": false }
  ],
  "hands": [              // 最近 30 手，旧的在前
    {
      "handNo": 1,
      "at": 1730000000000,
      "dealerSeat": 0,
      "board": ["5s", "9s", "Ts", "2c", "Qs"],
      "pot": 240,
      "showdown": true,
      "awards": [{ "seat": 1, "name": "阿宝", "amount": 240, "handName": "一对 10" }],
      "players": [
        { "seat": 1, "name": "阿宝", "before": 1000, "after": 1180, "delta": 180, "committed": 60, "folded": false }
      ]
    }
  ]
}
```

- `buyIn` = 起始筹码 + 累计补码；`delta = chips - buyIn` 即净输赢。
- 牌局进行中时 `chips` **已包含**本手投入的 `inPlay`，这样账本随时对得上（不会把底池算漏）。
- 只有公开信息（公共牌、赢家、筹码），不含未摊牌的底牌。

## 2. REST

所有接口返回 JSON，允许跨域（`Access-Control-Allow-Origin: *`）。`token` 是加入房间时拿到的凭证。

| 方法 | 路径 | 请求体 / 参数 | 返回 |
| --- | --- | --- | --- |
| GET | `/api/health` | — | `{ok,version,uptime,rooms}` |
| GET | `/api/rooms` | — | `{rooms:[{code,name,seats,players,online,sb,bb,startChips,phase,handNo,host,createdAt}]}` |
| POST | `/api/rooms` | `{nickname,name,settings}` | `{code,token,playerId,seat}` |
| GET | `/api/rooms/:code/view` | — | `{room,table}` 旁观视图（不含底牌） |
| GET | `/api/rooms/:code/history` | — | `{hands,players,totalHands}` 对局记录 |
| GET | `/api/rooms/:code/chat` | `?n=100` | `{code,messages:[...]}` 聊天记录 |
| POST | `/api/rooms/:code/join` | `{nickname,token?}` | `{token,playerId,seat}` |
| GET | `/api/rooms/:code/state` | `?token=&since=0&wait=20` | `{seq,state}`（长轮询，最多挂 20s） |
| POST | `/api/rooms/:code/action` | `{token,action:{type,to?}}` | `{ok,error?,state}` |
| POST | `/api/rooms/:code/start` | `{token}` | `{ok,error?,state}` |
| POST | `/api/rooms/:code/chat` | `{token,text}` | `{ok}` |
| POST | `/api/rooms/:code/rebuy` | `{token}` | `{ok,state}` |
| POST | `/api/rooms/:code/sitout` | `{token,value}` | `{ok,state}` |
| POST | `/api/rooms/:code/kick` | `{token,playerId}` | `{ok}` |
| POST | `/api/rooms/:code/leave` | `{token}` | `{ok}` |
| GET | `/api/rooms/rows` | — | `{rows:[...]}` 房间表（云数据表同构） |
| GET | `/api/hands` | `?n=30` | `{hands:[...]}` 战绩表 |

### 2.1 一次完整的 REST 对局

```bash
# 1) 建房
curl -X POST http://127.0.0.1:18080/api/rooms \
  -H 'Content-Type: application/json' \
  -d '{"nickname":"阿宝","settings":{"seats":3,"startChips":1000,"sb":10,"bb":20,"autoStart":false}}'
# → {"code":"592479","token":"47dc…","playerId":"p1_…","seat":0}

# 2) 第二个人加入
curl -X POST http://127.0.0.1:18080/api/rooms/592479/join \
  -H 'Content-Type: application/json' -d '{"nickname":"阿呆"}'
# → {"token":"03ec…","playerId":"p2_…","seat":1}

# 3) 房主开局
curl -X POST http://127.0.0.1:18080/api/rooms/592479/start \
  -H 'Content-Type: application/json' -d '{"token":"47dc…"}'

# 4) 轮询状态（没变化时挂 20 秒）
curl 'http://127.0.0.1:18080/api/rooms/592479/state?token=47dc…&since=0&wait=20'

# 5) 轮到自己时行动
curl -X POST http://127.0.0.1:18080/api/rooms/592479/action \
  -H 'Content-Type: application/json' -d '{"token":"47dc…","action":{"type":"raise","to":60}}'
```

### 2.2 行动参数

| type | to | 校验 |
| --- | --- | --- |
| `fold` | — | 任何时候 |
| `check` | — | 本街无人下注（`toCall == 0`） |
| `call` | — | `toCall > 0`，不足额时自动成为全下 |
| `raise` | 加注后的本街总额 | 必须 `> currentBet`；不足最小加注时只有"全下"才合法；已行动且未遇到完整加注时只能跟/弃 |
| `allin` | — | 推入全部筹码 |

## 3. 错误示例

```json
{ "t": "error", "message": "还没轮到你行动" }
{ "t": "error", "message": "最少加注到 100" }
{ "t": "error", "message": "房间不存在，请检查房间号" }
{ "t": "error", "message": "房间已满" }
{ "t": "error", "message": "只有房主可以开始牌局" }
```

REST 的错误用 HTTP 状态码 + `{error}`：`400` 参数/规则错误、`401` token 无效、`404` 房间或接口不存在。
